## 🧩 ¿Qué puedo desarrollar?

- **Desarrollo Backend:** construcción de servicios, lógica de negocio, APIs REST e integración de sistemas.
- **Desarrollo Web:** creación de aplicaciones web y funcionalidades frontend.
- **Gestión de bases de datos:** diseño de estructuras, relaciones, consultas SQL y administración de información.
- **Integración de servicios:** comunicación entre aplicaciones mediante APIs REST, HTTP/HTTPS y procesamiento JSON.
- **Desarrollo de software:** mantenimiento, implementación de funcionalidades, arquitectura MVC y solución de incidencias.
- **Gestión y transformación de datos:** conocimientos de procesos ETL y manejo de diferentes motores de bases de datos.
